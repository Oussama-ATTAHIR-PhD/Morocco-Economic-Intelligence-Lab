# Executive Summary

The **Morocco Economic Intelligence Lab (MEIL)** is an independent open research initiative dedicated to producing **high-quality, reproducible, and policy-relevant economic intelligence** for Morocco.

Rather than publishing isolated analyses, the Lab develops **structured research programs** built upon official datasets, transparent methodologies, applied economics, econometrics, and modern Python workflows.

The ambition is simple:

> **Transform official economic data into strategic insights for decision-makers.**

---

# Mission

The Lab aims to bridge the gap between **official statistics** and **strategic decision-making**.

Each study is designed to answer an important economic question using:

* Official datasets
* Applied economics
* Statistical analysis
* Econometrics
* Data visualization
* Reproducible Python workflows

Every analysis is fully documented and reproducible.

---

# Vision

The long-term objective is to build one of Morocco's leading open repositories dedicated to:

* Economic Intelligence
* Sector Intelligence
* Public Policy Analytics
* Market Intelligence
* Living Standards
* Entrepreneurship
* Investment Analysis

The project follows international best practices inspired by the analytical approaches of institutions such as the World Bank, OECD, IMF and central banks, while remaining entirely independent.

---

# Why This Lab?

Most economic analyses available online suffer from one or more of the following limitations:

* Lack of reproducibility
* Limited methodological transparency
* Absence of source code
* Weak data visualization
* Limited policy relevance

MEIL addresses these limitations by combining:

* rigorous economic reasoning;
* transparent methodologies;
* reproducible Python pipelines;
* executive-oriented reporting.

---

# What Makes This Lab Different?

Unlike a traditional data science portfolio, this repository focuses on **decision support**.

Python is **not** the final product.

Python is simply the analytical engine used to produce:

* Economic studies
* Sector reports
* Executive summaries
* Strategic dashboards
* Decision-support indicators
